# MoonOptimizer

Client-side optimization mod for Minecraft 1.21.11 (Fabric) with a compact
performance HUD.

## Requirements

- Minecraft Java Edition 1.21.11
- Fabric Loader 0.18.1 or newer
- Fabric API for Minecraft 1.21.11
- Java 21
## Controls

| Key | Action |
| --- | ------ |
| F7 | Show/hide the HUD |
| F8 | Cycle optimization profile |
| F9 | Enable/disable auto-boost |

All keys can be rebound in Options → Controls → Key Binds (category "MoonOptimizer")
